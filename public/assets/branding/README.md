# ArcRank logos

Exported from the original vector artwork in the Lavalab Figma file, Branding page.

- Wordmark: Frame 5 (`18:1247`), cropped to the artwork bounds with the background removed.
- Symbol: Frame 6's vector (`18:1260`).
- `*-dark.svg`: white artwork on transparency for dark surfaces.
- `*-light.svg`: #101010 artwork on transparency for light surfaces.
- `arcrank-favicon.svg`: adapts to the browser's preferred color scheme.

Original vector paths and proportions are preserved, including the outlined wordmark lettering. No font is needed to render these assets.
